# PhotogrammetryApp

## 项目简介

本项目是《摄影测量学》课程编程实验，基于 **C++ / MFC** 和 **Eigen** 库实现：
- **空间后方交会**：利用不少于4个控制点的像点坐标与地面坐标，通过最小二乘迭代解算单张影像的外方位元素（摄站坐标 Xs,Ys,Zs 和姿态角 φ,ω,κ），并输出单位权中误差、各参数中误差及协因数矩阵。
- **空间前方交会**：根据左右影像的外方位元素和同名像点坐标，通过点投影系数法（或最短距离法）重建地面点的三维坐标。

程序采用图形化界面（MFC 对话框），可方便地录入控制点数据、管理像点与地面点对应关系，并实时显示计算结果。

---

## 主要功能

- **控制点管理**  
  - 手动添加/删除控制点（像点坐标 x,y + 地面坐标 X,Y,Z）  

- **空间后方交会**  
  - 自动估算摄站初值（利用比例尺与平均地面高）  
  - 数值差分构造雅可比矩阵，最小二乘迭代求解  
  - 输出外方位元素、单位权中误差 σ₀、各参数中误差  
  - 显示 6×6 协因数矩阵（对应 Xs,Ys,Zs,φ,ω,κ）

- **空间前方交会**  
  - 输入左右片外方位元素、内方位元素及同名像点坐标  
  - 计算像空间辅助坐标 (u,v,w)、投影系数 N1,N2  
  - 输出地面点坐标 (X,Y,Z) 及两条射线的残余距离

## 编译与运行

### 开发环境

- **操作系统**：Windows 10/11  
- **IDE**：Visual Studio 2022（含 MFC 组件）  
- **依赖库**：Eigen 3.4 或更高版本（头文件库）  
- **其他**：GDI+（系统自带，用于图标显示）

### 编译步骤

1. **安装 Visual Studio 2022**  
   安装时勾选“使用 C++ 的桌面开发”和“适用于最新 v143 生成工具的 C++ MFC”。

2. **配置 Eigen 库**  
   - 从 [Eigen 官网](https://eigen.tuxfamily.org/) 下载最新压缩包并解压。  
   - 在 VS 项目中：项目属性 → C/C++ → 常规 → 附加包含目录 → 添加 Eigen 的 `Eigen` 文件夹路径（如 `D:\libs\Eigen\include`）。  
   - 由于 Eigen 是 head‑only 库，无需链接 `.lib` 文件。

3. **打开解决方案**  
   双击 `PhotogrammetryApp.sln` 或通过 VS 打开项目文件夹。

4. **选择配置**  
   - 解决方案配置：`Release`  
   - 解决方案平台：`x64`（推荐）或 `x86`

5. **编译**  
   点击菜单栏“生成” → “生成解决方案”（或按 `Ctrl+Shift+B`）。

6. **运行**  
   按 `F5` 启动程序。

## 使用方法

### 后方交会流程

1. 在“控制点管理”区域录入至少 **4 个**控制点（像点坐标 + 地面坐标）。  
   - 每行输入 `x (mm)`、`y (mm)`、`X (m)`、`Y (m)`、`Z (m)`。  

2. 设置相机内方位元素：`f (mm)`、`x0 (mm)`、`y0 (mm)`（实验数据中通常 x0=y0=0）。

3. 设置摄影比例尺分母 `m`（例如 50000），程序将自动估算航高。

4. 点击 **“后方交会计算”** 按钮。  
   - 计算成功后，右侧“计算结果展示”区域将显示外方位元素 (Xs,Ys,Zs,φ,ω,κ)。  
   - “精度评定”区域显示单位权中误差 σ₀ 及各参数中误差。  
   - 下方的 6×6 表格显示协因数矩阵（未乘 σ₀²）。

### 前方交会流程

1. 在相应编辑框中输入左右片的外方位元素：  
   - `Xs1,Ys1,Zs1, φ1,ω1,κ1`（左片）  
   - `Xs2,Ys2,Zs2, φ2,ω2,κ2`（右片）

2. 输入相机内方位元素 `f, x0, y0`（单位 mm）以及同名像点坐标 `x1,y1, x2,y2`（单位 mm）。

3. 点击 **“前方交会计算”** 按钮。  
   - 程序将计算像空间辅助坐标 `(u1,v1,w1)`、`(u2,v2,w2)`，投影系数 `N1, N2`，并给出地面点坐标 `(X,Y,Z)` 及残余距离。

4. 结果可直观显示在界面对应的编辑框中。

## 代码结构

| 文件 | 作用 |
|------|------|
| `PhotogrammetryAppDlg.h/.cpp` | MFC 对话框主界面，消息处理，控制点列表管理，调用后方/前方交会算法 |
| `Resection.h/.cpp` | 空间后方交会类，实现旋转矩阵、共线方程、数值差分迭代、精度评定 |
| `Forward.h/.cpp` | 空间前方交会函数，支持两种交会模式（点投影系数法 / 最短距离中点法） |
| `pch.h` | 预编译头，包含常用系统头文件和 Eigen 引用 |

## 常见问题

**Q1：后方交会迭代失败或结果明显错误？**  
- 确保至少使用 **4 个**控制点，且控制点不能近似共线。  
- 检查比例尺分母 `m` 是否正确（影响航高初值）。  
- 若收敛阈值过严，可适当放宽 `limitPos` 和 `limitAng`（代码中默认分别为 1e-3 m 和 1e-6 rad）。

**Q2：前方交会提示“射线平行或退化”？**  
- 检查左右片姿态角是否设置正确（尤其 κ 角符号）。  
- 确保同名像点坐标量测准确，且两射线确实能够相交。

**Q3：Eigen 编译错误“找不到头文件”？**  
- 确认在项目属性中正确添加了 Eigen 的附加包含目录。  
- Eigen 只需包含 `Eigen/Dense` 即可，无需额外配置。
